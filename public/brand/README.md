# Identité visuelle — assets du site Portfolio

## Photo de profil (site uniquement)

Si vous souhaitez une photo sur le **site Portfolio** (pas LinkedIn) :

1. Préparer une image réelle (JPG/WebP, 800×800+).
2. Enregistrer : `public/brand/profile.jpg`
3. Dans `src/data/profile.ts` : `photo: "/brand/profile.jpg"`

Les assets LinkedIn (photo / bannière) sont personnels et **ne doivent pas** être placés ici ni commités dans ce repository.
